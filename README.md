# FlipQuest 🎮

FlipQuest is a responsive, image-based memory matching game built using HTML, CSS, and vanilla JavaScript.

Players are given a brief preview of all cards and must then match **four identical cards** using memory and logic. The game works smoothly on both mobile and desktop browsers.

## Features
- Image-based memory cards  
- 4-card matching difficulty  
- Initial card preview before gameplay  
- Responsive design (mobile & desktop)  
- Reset button with reshuffle  
- Visual feedback for matched cards  

## Tech Stack
- HTML  
- CSS  
- JavaScript (Vanilla)

## How to Play
1. Observe the cards during the initial preview.
2. Click cards to flip them.
3. Match four identical images to lock them.
4. Match all cards to win the game.
